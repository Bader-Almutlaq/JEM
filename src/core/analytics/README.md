# analytics

The formulas, as pure functions over plain data: effective reps and RIR, estimated one-rep max, personal strength curves, strength trend, hard sets, fractional sets and volume zones, percent of max, RPE charts, linear trend and time bucketing.

Every file cites its source in `reports/Workout tracker app research.md` in its doc comment, or is marked `Heuristic:` with the reason. Test formulas against the worked examples in the report. Queries in `../queries` feed these functions; they do not re-derive them.
